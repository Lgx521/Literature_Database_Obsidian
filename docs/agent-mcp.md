# Agent MCP (retired in 4.9.0)

The published 4.8.5–4.8.6 releases included Agent MCP. The **4.9.0** release removes its interface, loopback service and Codex connection setup. Use [direct workspace maintenance](workspace-agents.md), or the optional [DeepSeek Beta](deepseek-beta.md). No MCP service is required for either workflow.
