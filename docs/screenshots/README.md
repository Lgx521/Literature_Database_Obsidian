# Screenshot provenance

Overview, tag map and AI review area captured on 2026-10-15 with Literature Database **4.9.0**; the other images remain from 2026-10-14 / **4.8.0**. Captured with Obsidian **1.14.4** on macOS, the default light theme and the plugin's English interface. These are application captures from a separate **Literature Database Demo 4.8.0** vault, not UI mockups. Captured through the official Obsidian CLI (`dev:cdp` / `Page.captureScreenshot`, with `eval` to navigate the demo), without Computer Use, cursor overlays or operating-system window borders. PNG captures were converted to JPEG for the README; the interface was not retouched. The AI image uses a CDP clip of the result-review area.

| Image | Demonstrates |
| --- | --- |
| `library-overview.jpg` | Title-based compact library, bookmarks, subcategories, organization provenance and circular section actions |
| `ai-organization.jpg` | Editable AI review form with two session-only sample proposals based on the public demo papers; no API request or Apply was performed for the screenshot |
| `tag-map.jpg` | Two-sided tag map, inline branch creation, independent checkboxes and human/AI tag colors |
| `writing-project.jpg` | Grouped project references, AoE deadline/countdown and project-specific notes |
| `citation-export.jpg` | Actual IEEE export preview generated by the bundled citation formatter |
| `review-tracker.jpg` | Fictional review assignments, venue deadline and inline status selector |

No personal vault tables, private notes, workspace settings, confidential review/submission manuscripts or PDFs are included in this repository. Notes, tag groups, memberships, priorities, reading states and writing projects were created for the demonstration. **ICLR2027 (Demo)** contains previously published papers used as fictional review tasks. Its deadline is illustrative, not an official conference date or a real assignment.
