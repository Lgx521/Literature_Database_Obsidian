# Screenshot provenance

Captured on 2026-10-13 with Literature Database **4.3.0**, Obsidian **1.14.4** on macOS, the default light theme and the plugin's English interface. These are unretouched application-window captures from a separate **Literature Database Demo** vault, not UI mockups. Click/remote-control indicators may be visible in the captures.

| Image | Demonstrates |
| --- | --- |
| `library-overview.jpg` | Compact three-pane library, search, reading status, priority, tags, venue labels and personal notes |
| `writing-project.jpg` | Project reference collections, AoE deadline/countdown and project-specific notes |
| `citation-export.jpg` | Actual IEEE export preview generated by the bundled citation formatter |
| `review-tracker.jpg` | Fictional review assignments, venue deadline and native inline status selector |

No personal vault tables, private notes, workspace settings, confidential review/submission manuscripts or PDFs are included in this repository. Notes, memberships, priorities, reading states and writing projects were created for the demonstration. **ICLR2027 (Demo)** contains previously published papers used as fictional review tasks. Its deadline is illustrative, not an official conference date or a real assignment.

Paper titles and bibliographic fields were read from the following public arXiv records on the capture date. The plugin's `citation-metadata.js` parser and bundled citation engine converted the official metadata into bibliography entries; no author, publication date or citation was supplied from model memory. The examples cite the arXiv versions rather than claiming a later conference publication.

- [Diffusion Policy](https://arxiv.org/abs/2303.04137)
- [Attention Is All You Need](https://arxiv.org/abs/1706.03762)
- [NeRF](https://arxiv.org/abs/2003.08934)
- [ReAct](https://arxiv.org/abs/2210.03629)
- [BERT](https://arxiv.org/abs/1810.04805)
- [Denoising Diffusion Probabilistic Models](https://arxiv.org/abs/2006.11239)
- [CLIP](https://arxiv.org/abs/2103.00020)
- [RT-1](https://arxiv.org/abs/2212.06817)

For future captures, build the plugin from the source version being documented, install it in an isolated vault using the empty templates, and use only public papers and explicitly fictional task data. Confirm the demo vault title before every screenshot. Do not copy or sanitize a personal vault to create a demo. Only commit reviewed screenshot assets and documentation, never the demo PDFs or local Obsidian settings.
