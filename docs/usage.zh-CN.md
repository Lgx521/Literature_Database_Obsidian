# 使用指南

当前版本为 4.9.5，支持桌面及移动端，需 Obsidian 1.8.7+。安装 Release 的三个运行文件后启用插件，点击左侧文献库图标，在空库中选择「创建文献库」。初始没有分类或写作项目，需要用户点击 ＋ 自行创建；README 截图中的分类仅为演示。新安装默认不自动打开文献库，也不接管 Markdown 源表，可在「设置 → Literature Database」分别开启。已有文献库保留此前的行为。

打开 Literature Database。顶部标签显示「文献库」或「Library」，当前分类、状态或项目只在列表上方显示一次。

左侧栏标题旁的语言图标可切换「跟随 Obsidian」「中文」「English」，也可以从命令面板运行「切换界面语言…」。默认跟随 Obsidian；切换前需保存或取消编辑，个人内容保持原文。后台文件统一为 `library.md`、`collections.md`、`reviews.md` 和 `submissions.md`；升级自动备份并改名，表格内容和旧回收记录保留。

- 审稿详情的「状态」可直接选择待审、在审、完成；默认无边框，选择后立即保存，未保存 Notes 保留。
- 中间列表和右侧详情统一显示篇名，实际 PDF 文件名在右侧以小字显示。新导入时原文件名作为临时篇名，可在「编辑」中修改；修改篇名不会重命名 PDF。单击文献查看右侧详情；双击或 Open ↗ 使用系统默认应用打开 PDF。
- 分类与写作项目旁的 ＋ 新建分组；右键重命名在侧边栏原位输入，Enter/失焦保存，Esc 取消；上下拖动分组调整顺序。
- 拖入分类/写作项目增加归属，不会离开原分类，也不复制 PDF。Cmd/Shift 可多选论文批量拖入。同类集合间 Cmd 拖动或右键「移到…」移除当前来源归属；跨分类/项目拖入始终添加。
- 分类/项目内按 Delete、右键「从当前…移除」或取消集合勾选，会移除当前归属。如果这是最后一个归属，弹窗提示并让你选择取消或整篇移至回收站，不能直接解除唯一归属。分类和写作项目合并计数；「全部文献」「在读」等系统视图不算归属。「移到」可用新归属替换唯一归属。
- 有多个归属的文献点击「移至回收站」或按 Delete/Backspace 时，先选择「仅从当前集合移除」或「整篇移至回收站」。后者会从所有分类/项目中隐藏该文献，恢复时原归属和项目备注一并恢复。在「全部文献」等没有当前集合的视图中，只提供取消或整篇回收。批量选择中如有唯一归属的文献，不提供整批仅移除归属的选项。确认期间归属或项目备注发生变化则停止，重新选择后再操作。
- 只有一个归属的文献直接点击「移至回收站」，以及收件箱、审稿、投稿的回收操作，仍立即执行。处理中显示状态，不需要重复点击。删除分类/项目本身仍保留文献；无分类文献出现在「未分类」。
- 写作项目保存某项工作用到的参考文献，项目备注单独保存，通用 Notes、阅读状态、优先级和 Venue 在所有位置共享。项目与投稿独立；新建时可主动选择另一侧已有项，只共享 DDL。
- 收件箱接受 Finder 拖入 PDF，也支持复制一个或多个 PDF 后在列表空白处右键「粘贴」；两种方式都复制并保留原件及配套批注，同名文件存入独立子目录，文件名永远不改。审稿/投稿继续按 Venue 管理任务，DDL 属于 Venue；暂存区无 DDL。删除 Venue 将任务移回暂存区。

回收站左侧勾选多条记录，或点顶部「全选」，再用「恢复所选」或「彻底删除所选」批量处理；也保留单条操作。批量恢复直接执行，批量彻底删除整批只确认一次，删除所选记录和归档 PDF/批注，无法恢复；仍被其他记录使用的附件保留。处理中显示进度，结束显示成功/失败数量；失败项保留勾选并显示具体原因，方便重试，同名附件不会被覆盖。

## AI 整理

DeepSeek Beta 已包含在正式版中，默认开启，可在插件设置中关闭。点击侧栏「AI 工具 → DeepSeek Beta」，输入自己的 API Key，获取并选择模型，然后整理收件箱或文献库中信息不完整的论文。

收件箱先点击「规划收件箱」：每批最多 20 篇，统一提出分类与标签，优先复用已有名称。可修改名称以合并相近建议，点击「确认方案并逐篇整理」后，逐篇补充篇名与 TL;DR；已确认的分类不会再由模型重新选择。生成方案和预览都不写入文献库，最后点击应用才归档。后续批次复用已经应用的词表。

结果包含篇名、TL;DR、标签、分类及子类；论文明确提出的方法名称或简称会保留在 TL;DR 中，方便搜索；可以逐项编辑，通过标签思维导图添加或调整标签，确认后「应用到文献库」或「全部应用」。明显不同方向的文献可以提出新标签／分类建议。关闭面板后任务继续，侧栏显示进度，再次打开保留当前会话的结果和编辑。

支持在设备上安全记住密钥，也可设置口令加密后通过 iCloud 同步。只有主动开始整理才会发送所选 PDF 文本与分类标签；AI 不生成引用信息。详见 [AI 使用说明](deepseek-beta.md)。

设置中的「字段设置」可修改阅读状态、优先级等名称和选项，新增文本／单选字段，或隐藏不使用的字段。

## 直接归档与整理来源

Mac 可把外部 PDF 直接拖到具体分类或写作项目（左侧分组或其中央列表），保留原件与批注，立即建立一行记录并加入目标集合。TL;DR、标签为空，阅读为待读、整理为待整理。已收录的库内 PDF 再拖到项目只增加归属。全部文献与未分类不是外部 PDF 的导入目标；批量待决定归属的文献仍可放收件箱。

右侧阅读状态旁有「整理状态」，默认无边框：待整理、AI 已整理、人工完成、自动整理。选择人工完成后，遵守 AGENTS.md 的 Agent 会跳过整条文献，即使部分字段为空；改回待整理即可重新交给 Agent。成功读取篇名、日期或引用后会从待整理变为「自动整理」，表示获得过自动元数据，不表示引用和摘要已经齐全。完全失败仍为待整理。不会把 AI 已整理或人工完成降级。筛选「待补充元信息」包括待整理、自动整理及 AI 已整理但仍缺篇名、标签或 TL;DR 的条目。整理仍需手动触发，不会在后台自动调用模型。

人工新增标签淡紫色，AI 新增标签灰色；悬停可看来源和 Agent 名。篇名和 TL;DR 也记录字段来源。未知来源的历史内容保持中性色，不推断由谁填写。Agent 不覆盖人工或未知来源内容、不删已有标签、不改 Notes、阅读状态、优先级或引用；拿不准的内容留空并报告。

PDF 及批注保持初始文件名，包括数字 arXiv 名称。已有文件不改回。真实篇名独立保存在源表，与 PDF 路径对应；同名导入通过子目录解决，不加文件名后缀、不覆盖。来源信息与整理状态同样保存在 library.md；没有第二份元数据库。

## 引用

发表时间可随确定性识别自动补齐为 `YYYY.M`，只有年份时保留 `YYYY`。PDF 创建/修改日期不能当发表时间；arXiv 使用首版提交日期，不用 v2/v3 修订日期。自动生成的年份可补月份，人工或来源未知的已有日期保留。日期证据保存在该字段的来源信息中。「自动整理」仍允许 Agent 补充 TL;DR、标签，随后改为 AI 已整理。

不需要上传引用文件。插件运行时新收录的公开文献会按需读取 PDF 元数据；资料不足时识别 DOI/arXiv ID，查询 Crossref/arXiv，并核对篇名。没有标识时检索篇名，只有唯一标题与首页作者匹配才写入。导出也会识别缺失引用；已有引用不重复获取、不覆盖。不用 AI 生成引用，也不使用 PDF 创建时间或修订时间充当首发时间。

识别失败可稍后重新导出，或在 Obsidian 命令面板运行 Literature Database 的「重新识别缺失引用」。未保存 Notes/编辑会阻止自动写入，先保存再重试。审稿/投稿附件不进行联网引用识别。没有周期扫描；启动不扫描全库，解析只读前两页并释放文档。

列表工具栏「导出…」或项目右键「导出参考文献…」提供 BibTeX、APA 7、IEEE 和标题列表。默认导出当前可见列表（含筛选），可以选择只导出选中文献。APA/IEEE 保存为带排版的 HTML，并支持复制引用；BibTeX 保存 `.bib`；标题列表保存 `.txt`。IEEE 编号按当前导出列表顺序，写稿时须按实际引用顺序调整。

引用资料缺失、不完整或键冲突会显示缺失清单，支持单独保存；不会填入猜测信息。标题列表每行只输出论文真实篇名，缺少篇名时列入缺失清单，绝不用文件名替代。文件保存在 vault 的 `exports/`，带时间戳，不覆盖之前的导出。

## 外部 Agent 与标签维护

从 4.9.0 起不再提供 Agent MCP。直接让外部 Agent 打开 vault 文件夹、阅读 `AGENTS.md`，即可按维护约定整理收件箱、补全空缺或协助迁移文献。无需本地 MCP 服务或连接配置，详见 [工作区维护](workspace-agents.md)。

标签图中右键标签／分组（触控长按）可原位重命名，修改会同步子标签、词表与文献归属，并保留来源颜色。也可删除整个标签分支，确认前显示影响数量。桌面与移动端均提供保存、取消按钮。


## 4.5.2 移动端

iPhone/iPad 已启用插件；手机使用紧凑工具栏、默认折叠筛选、接近桌面端的平面列表与详情区，二者以 3px 分隔线区分，不使用圆角卡片、阴影或区块间距。详情右上角可展开/收起，手机上下布局使用 240ms 平滑过渡；系统启用“减少动态效果”时关闭动画。切换过程保留选中文献和 Notes 草稿；宽屏 iPad 保留列表与详情并排。手机顶部只保留系统报告的刘海／状态栏安全区高度，不叠加隐藏标题栏的占位；iPad 顶部和桌面布局保持不变。更新后若仍显示旧工具栏，请等待插件文件同步完成，再在该设备关闭并重新启用插件。

左上角打开分类侧栏，分组旁的省略号可打开重命名、DDL、删除等菜单。顶部「＋」从“文件”选择 PDF，可导入收件箱、具体分类/项目、审稿或投稿；同名文件放入独立子目录，文件名不变。总文献列表不确定归属时，请先进入收件箱或具体集合。新导入的公开文献沿用自动元数据识别与整理状态；审稿/投稿不联网检索。

移动端只能读取主动选中的文件，无法自动寻找相邻批注或读取 macOS 扩展属性。需要批注时一起选择同名 .skim/.fdf/.xfdf，或经 iCloud 同步；原文件不被删除。移动端 Open 在 Obsidian 中打开 PDF，不调用 Mac 的 Skim。Notes、状态、Venue、集合、回收与引用导出仍使用同一份 Markdown 数据。

验证范围：Obsidian 官方移动模拟、禁用 Node/Electron 的运行测试。尚未在实体 iPhone/iPad/Android 验收；跨设备 iCloud 同步仍需在接收设备确认。

## 书签（4.6.0）

4.6.1 在筛选栏增加「仅书签」开关：只筛选当前分类或写作项目中的书签文献，不跳转到全局书签页。可与搜索、阅读状态、整理状态和标签组合使用；再点一次或「清除筛选」恢复当前范围。筛选块按当前选中文字收缩，长标签在窄屏内截断。

左侧「书签」位于收件箱与在读之间。选中文献后，点击右侧详情顶部的书签图标添加或取消；已添加时显示红色，列表中的文件图标右上角也会出现红色小书签。

书签页按左侧研究分类顺序分组，同篇属于多个分类时在每个分类下显示，没有研究分类的放在「未分类」。顶部篇数、导出与批量操作按论文去重。书签独立于阅读状态、分类和写作项目，回收后恢复仍保留；Agent 整理不能改动用户书签。

标签、Venue 与集合的新增／移除有短促轻弹或淡出反馈，遵循系统「减少动态效果」。书签保存只更新受影响的标记与计数，保留原来的详情控件、列表行、Notes 草稿和滚动位置，不让无关按钮临时变灰。

## 子类（4.7.0）

分类和写作项目支持一层子类。右键父级选择「新建子类」，在侧栏输入名称，Enter 保存、Esc 取消；右键子类可原位重命名或删除。子类可以在同一父级内拖动排序，父级旁的箭头展开／收起，使用约 180ms 的轻量过渡，遵循系统「减少动态效果」设置，不重建无关控件。侧栏中「未分组」数量为 0 时隐藏，有未分组文献后自动出现；用户创建的空子类仍保留。

点击父级，中间列表按子类顺序分组，「未分组」在最后；点击子类只看它的论文。每篇论文在同一父级下只出现一次，在不同分类／项目中可以有不同的子类位置。标签保持多选，用于搜索和筛选，不再让论文重复出现。书签继续沿用按研究分类分组的规则。

- 将论文拖到同一父级的另一个子类，或右键论文选择「设置子类…」，即可更换位置；支持多选。右侧「分类」显示完整归属路径，点击也可选择子类。
- 普通拖到其他分类／项目的子类会增加目标归属；同类集合间 Cmd 拖动会移动当前来源归属，跨分类／项目仍只添加，不复制 PDF。拖到父级时，已有文献保留原子类，新加入的文献进入未分组。
- 右键「加入分类／项目…」和「移到…」会在有子类的集合下展开二级菜单，无子类的集合直接选择。操作提示区分新加入、已移动和目标已有。切换分类、子类、项目或智能视图保留搜索词；主动清除筛选及导入聚焦仍会重置筛选。
- 外部 PDF 可直接导入子类，保留文件名并沿用现有元数据识别；手机使用当前子类页面的「＋」。
- 中间列表整段子类区域都可接收拖入，空子类也保留标题。拖着 PDF 靠近列表上下边缘会自动滚动，也可用滚轮／触控板滚动；紫色区域始终指示光标下的目标子类，松手才导入。
- 导入完成会清除遮挡结果的筛选，选中本批成功导入的文献，并将第一篇滚到可见位置。从中间分组列表导入时仍停留在父级页面；自动识别篇名改变排序后，会保持原本可见的选中论文可见。
- 「移出子类」回到父级未分组；删除子类也将其中论文移回未分组，不回收论文。移出父级和整篇回收继续使用现有归属检查。
- 导出当前子类时只导出该子类列表；父级导出全部论文。项目备注在更换子类时保留，项目 DDL 由父级统一管理。

既有文献不会根据标签自动分配子类。没有子类信息时显示在原父级的未分组中，不改源数据。信息仍在原有 Markdown 中维护，不建立单篇文件；旧两列集合表在第一次分配子类时，只为对应集合追加可选第三列。右侧顺序保持 TL;DR、分类、标签、Venue、Notes。


## 搜索（4.9.5）

输入关键词后，下拉菜单显示匹配论文与所属分类／子类，不改变中间列表。默认搜索当前筛选后的列表；勾选「在全部文献中搜索」后搜索全库公开文献。点击结果会进入其分类并选中、滚动定位论文；多个归属时优先当前分类／项目，否则按侧栏分类顺序选择。搜索词保留，定位时清除可能隐藏目标的筛选。支持方向键选择、Enter 跳转和 Esc 关闭。

桌面搜索框 × 只清空文字并保留焦点；手机 × 清空并关闭搜索、收起键盘。移动端菜单也有关闭按钮，可保留搜索词并收起键盘。结果菜单最大宽度 640px，随屏幕收窄，只纵向滚动；悬停可查看完整篇名和分类路径。

「高级搜索」筛选中间列表，支持篇名、标签、发表时间、Venue、TL;DR、文件名和 Notes，以「全部满足（交集）」或「任一满足（并集）」组合条件。标签通过导图选择，不修改文献标签；条件在「应用」后生效，取消保留原条件。高级条件与状态等筛选共同作用于当前分类／项目；全库关键词搜索不受当前分类筛选限制。发表时间支持年份或年月（例如 `2026.5`），只有年份的记录不会匹配具体月份。搜索只读取现有本地数据。

## 标签思维导图与多选筛选（4.8.0）

右侧「标签」旁的圆形 ＋ 打开思维导图。根节点 ＋ 新建视觉分组，分组或标签末端 ＋ 原位输入新标签／子标签，Enter 保存、Esc 取消。创建只加入词表，勾选才分配给当前论文；父子标签独立选择。公共 `research/` 前缀仅在界面隐藏，实际标签不变。分支向左右展开，支持搜索、折叠、拖动画布与缩放。

人工添加的标签淡紫色，AI／未知来源灰色。勾选不切换论文、不提交或丢失 Notes 草稿。可选 tags.md 只记录词表及视觉分组，首次明确编辑才创建；论文标签和来源仍在 library.md 的同一行。

顶部标签筛选可多选，默认并集：包含任一所选标签即可，父标签不隐含匹配子标签。选择面板保持打开，支持搜索与清空；筛选不修改论文。公开文献右键增加添加／取消书签，支持多选：全已收藏则取消，否则补齐所有选中文献。

移动端分类／项目展开箭头有独立的 44×44 触控区。修复移动样式把加号、收藏、删除等图标挤宽的问题。iPad 保留 Obsidian 原生侧栏，左右布局中的详情展开／收起也有平滑过渡；手机保留上下布局动画，快速反向点击与 Notes 草稿均受保护，遵循减少动态效果设置。

## 面板尺寸与移动端编辑（4.8.3）

鼠标移到列表与详情的分界线上会加粗高亮，按住即可拖动。iPad／手机也可按住分界线滑动：左右布局调详情宽度，上下布局调列表高度。触控命中区比线条更宽；左右各保留至少 280px，上下列表／详情分别保留 140px／180px，空间不足时自动缩小限制。

尺寸记录在 Obsidian 工作区视图状态中，左右宽度与上下比例分别保存。详情放大／还原继续保留动画，收起后恢复所选尺寸；不会切换文献或丢失 Notes 草稿。分界线获得键盘焦点后可用方向键调整、Shift 加大步长、Home／End 到达边界；拖动时 Esc 取消。

移动端侧栏重命名可点键盘「完成」，也可点输入框外自动确认，分类、项目、Venue 和子类一致。中文输入法候选确认不会提前提交；空白或未修改的名称直接结束编辑，校验失败保留输入供修正。

标签图新建分组／标签／子标签时，移动端输入框旁有勾号和 ×，分别保存和取消尚未创建的分支。取消不会关闭标签图，也不会改动已有标签选择。

## 触控拖动与优先级（4.8.4）

分界线可直接按住拖动，不需要先长按等待；拖动不会同时拉出 Obsidian 两侧栏。触摸松开或取消后自动清除高亮，鼠标悬停与键盘聚焦仍有提示。

移动端公开文献列表的实际宽度达到 560px 时显示优先级，拖窄或分屏后空间不足则隐藏。判断依据是列表可用宽度，适用于 iPad，也随手动调整面板尺寸更新；审稿、投稿和收件箱列保持原样。


4.8.6 优化了源表刷新、标签图与 PDF 任务：隐藏页面暂停重绘，已知篇名导出不等待 PDF 队列；标签图关闭后释放资源，重新打开保留视口和折叠状态。可在命令面板使用「取消 PDF 识别与读取」取消当前及排队任务。桌面左侧栏最小宽度为 220px，并随界面字号增大；长名称省略，倒数日与篇数独立保留。
