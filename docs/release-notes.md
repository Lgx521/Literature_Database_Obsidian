Literature Database 4.10.0 brings web resources into your library and renders inline formulas with Obsidian’s built-in engine.

- **Web resources:** paste, drag or add URLs to Inbox, collections, subcategories and writing projects. Use the same tags, bookmarks, search, Notes and recoverable trash; open the original in your browser.
- **AI for webpages:** read the saved URL through DeepSeek Fetch, with direct-page fallback. Review a shared Inbox plan, edit the title, TL;DR, tags and placement, then apply. Planning and generation use up to 48,000 characters per item.
- **Editable Inbox tags:** choose existing tags in the mind map, remove proposed tags, and retain your confirmed selections through generation.
- **Collection menus:** fix native category/project submenus and membership toggles. Click a checked child or Ungrouped entry to remove that membership, with the existing last-membership safeguards.
- **Inline formulas:** show basic `$…$` math in titles, search results and TL;DR. Load the shared Obsidian engine only when needed; retain source text for copying, search and export.

Validation: 71 offline regression suites on macOS, locked dependency rebuild and release packaging checks. Inline math also passed application smoke checks and synthetic Chromium lifecycle/memory checks. Requires Obsidian 1.8.7+.
