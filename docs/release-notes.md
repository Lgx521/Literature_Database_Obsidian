Literature Database 4.8.6 reduces repeated refresh work and tag-map rendering, preserves active edits, and keeps sidebar deadlines readable at narrow widths.

- Merge file events and explicit writes into one refresh queue. Parse only changed source tables, retain unchanged list rows, and preserve selection, focus, scroll and unsaved Notes. Incomplete sync keeps the last good snapshot visible.
- Pause hidden views and resume after Obsidian shows them. Keep unchanged navigation controls mounted instead of rebuilding the sidebar.
- Coalesce tag-map pan/zoom to one animation frame and render only the viewport plus a buffer for large maps. Closing the map releases nodes, layout, observers, listeners and native-menu callbacks; reopening restores pan, zoom and folded branches.
- Export known paper titles without waiting for PDF recognition or loading the citation formatter. Load bibliography and APA/IEEE formatting only when needed. Existing title-list, BibTeX, APA and IEEE outputs remain byte-for-byte compatible with 4.8.5 fixtures.
- Serialize metadata and Agent MCP PDF extraction in one cancellable queue. Release PDF resources on completion, errors, timeout and cancellation; bound MCP evidence caches. Use **Cancel PDF recognition and reading** to stop queued and active PDF work.
- Keep names, deadline countdowns and paper counts in separate sidebar slots. The desktop library sidebar has a minimum width of 220px, increasing with larger interface text. Long names truncate while countdowns/counts stay visible. Native collapse and mobile drawer sizing are preserved.

In an isolated macOS Obsidian demo with 1,000 papers and 1,000 tags, median unchanged refresh time improved from 28.1 to 0.8 ms and expanded tag-map render time from 53.3 to 1.7 ms. These are scenario-specific renderer measurements, not a guarantee of total application memory. See [performance measurements and limits](https://github.com/Lgx521/Literature_Database_Obsidian/blob/4.8.6/docs/performance.md).

Requires Obsidian 1.8.7+. The existing Markdown schema, original PDF filenames, citations, personal fields and platform support are preserved. Full paper-list virtualization remains deferred.

Validation: 48 offline synthetic regression suites on macOS, including Node-free mobile execution, failed-sync recovery, refresh races, map lifecycle/culling, PDF cancellation and byte-for-byte citation fixtures. Actual Obsidian demo checks cover hidden-tab recovery, retained rows, tag editing with an unsaved Notes draft, repeated map opening/closing, narrow sidebar layouts and native collapse. Release CI also tests Linux (skipping two macOS-only suites), rebuilds the locked citation dependencies and validates assets before publishing. Community review and in-app update propagation are separate from this GitHub release.
